The storefront is live again, at /store.html. What you edit here is what a visitor sees: that page reads this same items.json, and the bowl, the menu and the Stack all route to it. Fields this editor does not show — kind, format, platforms, demo — are carried through untouched, so editing a plugin here will not strip the line that tells the store which simulation to open.

Two things to know about ids. Any id that is all digits gets renumbered on export, so the plugins use word ids (mindbloom, hydra) and are safe. And prices are deliberately empty: every plugin card says “price not set” until you put one here.

Getting paid. Each item names its own seller and its own Venmo, so a page listing several people’s work pays each of them. Set yours in You below and anything you add is stamped with it. The store’s PAY button opens venmo.com/<you>?txn=pay&amount=… with the amount taken from the price field, and prints your handle on the card as well — those prefilled links are reliable when a phone hands them to the Venmo app and patchy in a desktop browser, so the handle has to be readable either way. Nothing is processed here: this is a static site with no checkout, no escrow and no way to verify a payment happened.

How it works: Edit any field below — changes save automatically to your browser as you type. When you're done, click SAVE / EXPORT JSON to download an updated items.json, then upload that file to the root of your repository.

You

Set your name and your Venmo once. Everything you add after that is stamped as yours and its PAY button goes to you. This is stored in this browser only — it is not an account and it does not prove who you are. Anyone who can edit items.json can change who gets paid, so treat the file as the record.
